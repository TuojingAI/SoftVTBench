# Formal N=50 OOD protocol

The paper evaluates nine mutually exclusive, single-factor conditions:

1. lighting brighter, mild;
2. lighting brighter, strong;
3. lighting darker, strong;
4. mass heavier, mild;
5. mass heavier, moderate;
6. mass heavier, strong;
7. Young's modulus softer, mild;
8. Young's modulus softer, strong;
9. Young's modulus harder, strong.

The exact JSON values are bundled in this directory. The original formal
conditions-file SHA-256 was
`2ff37273d9c0cd6342ae48293fb94aba19d062a3d51ab615ac9a4a80d30826c9`.
The repository file uses `${SOFTVTBENCH_ROOT}` so it is relocatable. Its byte
digest therefore differs from the sealed internal path-only representation;
condition labels, levels, and JSON payloads are unchanged.
